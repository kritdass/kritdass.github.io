This is my personal website which also includes a blog with posts written by me.

## Development

The [devenv](https://devenv.sh) environment provides Bun and Node.js. With the devenv shell hook installed, run `devenv allow` once to enable automatic activation, or enter the environment with `devenv shell`.

Run `bun install`, then `bun run dev` to start the development server. Run `bun run build` to build the site.
